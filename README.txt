GRANDSTAY — GITHUB PAGES VERSION

This version contains ONLY HTML, CSS and JavaScript. It is designed to run as a static website on GitHub Pages.

HOW TO USE:
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload index.html, style.css, script.js and the assets folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish your website.

BOOKING FEATURES:
- Search rooms by dates and number of guests.
- Room capacity filtering.
- Browser-side date overlap check for bookings created in the same browser.
- Guest details form, price/tax calculation and booking reference.
- Booking lookup using reference and email.
- Cancellation.
- Dark mode and responsive layout.

IMPORTANT LIMITATION:
This is a front-end demonstration. Bookings are saved in the visitor's browser using localStorage. They are NOT shared with the hotel or other visitors/devices, and availability is not globally synchronized. Clearing browser data can remove bookings. There is no real payment processing, email confirmation, or actual hotel inventory. GitHub Pages cannot run a Node.js backend or database.

Room photos and Google Fonts are loaded from external services and need an internet connection.
