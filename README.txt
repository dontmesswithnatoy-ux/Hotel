GRANDSTAY HOTEL & SUITES — BOOKING DEMO

Open index.html in a modern browser.
Features:
- Responsive hotel booking landing page
- Check-in/check-out date validation
- Three selectable room types with sample nightly rates
- Guest capacity validation
- Live booking estimate with 12% sample tax
- No real availability check, reservation, or payment processing

Photography is loaded from Unsplash URLs, so an internet connection is needed to display room and hotel photos.
This is a front-end portfolio demo only.
